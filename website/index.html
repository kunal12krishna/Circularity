How it works.

Three moves, wherever a file is: Finder, the desktop, Mail, a browser download.

Drag
  1. 01

    Drag.

    Press on any file and start dragging. Several at once work too, and so do files from other apps.

  2. 02

    Tap Shift.

    A wheel of formats opens around your pointer. Shaking the pointer works too. No Accessibility permission, no key logging.

  3. 03

    Let go.

    Release on JPG and IMG_2041.jpg appears next to the original a moment later. The original is never changed.

    Rest on More for the rest.

    Crop, Cut out, one PDF from many pictures or one per picture, and the formats that didn't fit on the ring. Buttons you save from Resize or Compress show up here too.

    Cut out the background.

    Apple's on-device subject lifting keeps the subject and makes everything else transparent, saved as a PNG. Nothing leaves your Mac. Needs macOS 14 or later.

    A panel in the menu bar.

    Drop files on a preset, type commands like 50kb or 1920w after ⌘K, and find every result in Recent. Dark, light, or three layouts.

    What it doesn't touch

    Small, quiet, private

    promises.txt
    • 0 permissions: no Accessibility, no Input Monitoring, no Screen Recording. macOS never asks.
    • works on your Mac with Apple's own ImageIO, PDFKit and WebKit
    • never changes your original file
    • 12.5 MB of memory at rest, 0.02 % CPU. It sleeps until you drag a file.
    • reads the clipboard only when you press ⌃⌥V
    • uploads your files (it can't: there is no server)
    • checks for updates, unless you turn that on
    why.txt

    converting a file usually means: open an app, find export, pick a format, pick a folder, close the app.

    circularity makes it one move, right where the file already is.
